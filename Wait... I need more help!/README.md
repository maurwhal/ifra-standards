# Wait... I need more help!

Extra help, written for someone who does not use the command line.

Start with the file that matches what you are trying to do:

1. **[Easy way](1%20-%20Easy%20way.md)**
   The double-click app. Nothing to install. Try this one first. Windows only.

2. **[Command line way](2%20-%20Command%20line%20way.md)**
   Starts from installing Python. More setup, but it works on Mac and Linux too
   and gives you the extra formats (Excel, one row per CAS, the PDFs).

3. **[If something goes wrong](3%20-%20If%20something%20goes%20wrong.md)**
   The common error messages and what to do about each one.

4. **[What the columns mean](4%20-%20What%20the%20columns%20mean.md)**
   Every column in the spreadsheet, in plain language.

If none of this helps, open an issue at
<https://github.com/maurwhal/ifra-standards/issues> and describe what you did and
what happened.
